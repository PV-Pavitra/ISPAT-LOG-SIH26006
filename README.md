# ISPAT-LOG-SIH26006
ISPAT-LOG is an intelligent maritime decision support grid for Ministry of Steel (SIH 2026 • PS SIH26006). Features 30/60/90-day ocean freight rate forecasting, vessel chartering optimization, dynamic requisition matching, open carrier bid ranking, live AIS tracking, port congestion heatmaps, and landed cost analytics for SAIL &amp; RINL.
